# `v0.2.0` development baseline

Collected: 2026-07-28

This record freezes the public-source, synthetic-query, coverage, and
benchmark comparison points at immutable tag `v0.2.0`, commit
`a9928769184c5a74f56da169022073b872889885`. The exact values are in the
[machine-readable baseline](v0.2.0-development-baseline.json).

## Public contract source

The baseline contains 30 public PHP files under `src/`, excluding the closed
`src/Internal/` implementation. The recorded digest covers each sorted path and
its Git blob ID, so both public type names and their exact tagged declarations
are recoverable without copying a second source tree into the documentation.

Reproduce the public-source digest from a clone containing the tag:

```bash
git ls-tree -r --name-only v0.2.0 src \
  | rg '\.php$' \
  | rg -v '^src/Internal/' \
  | sort \
  | while IFS= read -r file; do
      blob=$(git rev-parse "v0.2.0:$file")
      printf '%s  %s\n' "$blob" "$file"
    done \
  | sha256sum
```

This is a historical comparison point, not the Phase 4 public-API compatibility
manifest. Later work may derive a signature-level manifest while retaining this
tagged source baseline unchanged.

## Synthetic queries

SHA-256 digests are recorded for the MariaDB, MySQL, and SQLite compiler
goldens, feature-coverage catalogue, public aggregate and connection contracts,
and both migration corpora. Reproduce an individual digest with:

```bash
git show v0.2.0:tests/Fixtures/Compiler/mysql.json | sha256sum
```

The files capture SQL, ordered binding, identifier, aggregate, connection, and
migration shapes. A changed digest is a prompt for semantic review, not proof
of regression by itself.

## Coverage

The release evidence passed all enforced floors: 93.07% overall line, 89.18%
overall branch, 97.74% compiler line, and 92.18% compiler branch coverage. Path
coverage was 6.75% and remained informational. The source measurements and
engine matrix are retained in
[`0.2.0` Phase 3 hardening evidence](0.2-phase-3-hardening.md).

## Benchmarks

The baseline records the maintained CI, historical-shape, migration, observer,
reference-size, and soak commands plus digests for the scenario catalogue,
migration benchmark, and committed migration control. Benchmark comparison
must use the same PHP runtime, PDO driver, database settings, workload profile,
and correctness digest; timings from unlike environments are not comparable.
