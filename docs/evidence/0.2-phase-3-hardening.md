# `0.2.0` Phase 3 type and test hardening

Date: 2026-07-26

Branch: `feature/0.2-candidate`

Decision: package `0.2-F` passed its type, behavior, branch-coverage, and
minimum/current engine gates.

## Public contract evidence

- Raw expression/query positional bindings and compiled bindings are published
  as lists. Runtime list/member checks remain at consumer-constructible
  boundaries.
- Join callbacks infer `JoinClause`; condition and `HAVING` callbacks infer
  `ConditionGroup`.
- `Cursor` is PHPDoc-generic without a runtime subclass hierarchy. Object and
  associative terminals infer `Cursor<stdClass>` and
  `Cursor<array<string, mixed>>` respectively.
- `CompiledQuery` validates binding members before accessing them.
  `QueryExecution` validates parameter-type listness/members, SQL, duration,
  affected rows, and transaction depth.
- The external-consumer fixture passes PHPStan level 9 independently through
  `composer phpstan:consumer`.

## Executable behavior evidence

Focused PHPUnit and direct-engine probes cover:

- mixed-null and null-only `IN`/`NOT IN` SQL three-valued logic;
- oversized integer strings without numeric conversion;
- PDO's last-value policy for duplicate result names;
- object access and associative rejection for numeric result names;
- cursor observation at execute/hand-off, with no second event for later fetch
  failure;
- MySQL-family DSN, buffering, prepare, persistence, and row-count policy
  rejection branches;
- runtime execution of the versioned aggregate-count contract cases.

The SQLite execution probe passed all 15 observations. Direct MariaDB and
MySQL execution smokes passed all 17 observations on each tested version.

## Branch and path coverage

The dedicated Xdebug 3.5.3 job uses path coverage and a separate Clover file.
The checker now fails when a configured branch metric is absent; a subprocess
regression test proves the failure behavior. PCOV remains the fast line-only
job.

## Engine-version matrix

Direct CI is parameterized over two exact fixture pairs:

| Fixture | MariaDB | MySQL |
|---|---:|---:|
| Minimum | 11.8.2 | 8.0.11 |
| Current | 11.8.8 | 8.0.46 |

Local acceptance executed native/emulated × buffered/unbuffered behavior
profiles plus execution, transaction, and migration smokes on all four exact
engine versions. Each version produced 48 observed profile cases, 17 passed
execution cases, 15 passed transaction cases, and 8 passed migration cases. CI
executes the same full matrix for both fixture pairs and archives separate
reports.
