## Reproducing the before metrics

Each command below must return the recorded value on a clone at tag `v0.3.0`:

```bash
# SQ-0402-01 compiler line counts
wc -l src/Internal/Compiler/MariaDbCompiler.php src/Internal/Compiler/MySqlCompiler.php

# SQ-0402-02 golden-write assertion counts
grep -c 'assertMatches\|assertSame' \
  tests/Compiler/MariaDbCompilerTest.php \
  tests/Compiler/MySqlCompilerTest.php \
  tests/Compiler/SqliteCompilerTest.php

# SQ-0402-03 statement doubles
ls tests/Unit/*Statement.php | wc -l

# SQ-0402-04 condition-dispatch implementations
grep -n 'private function addHaving\|private function addCondition' \
  src/QueryBuilder.php src/Internal/BuildsConditions.php

# SQ-0402-05 func_num_args() sites
grep -rc 'func_num_args' \
  src/Internal/BuildsConditions.php src/QueryBuilder.php src/JoinClause.php

# SQ-0402-06 magic-string literal sites in QueryBuilder
grep -c "'update'\|'share'\|'NOWAIT'\|'SKIP LOCKED'\|'INNER'\|'LEFT'" src/QueryBuilder.php
grep -c "'update'" src/Internal/Compiler/MariaDbCompiler.php src/Internal/Compiler/MySqlCompiler.php

# SQ-0402-07 Connection line count
wc -l src/Connection.php

# SQ-0402-08 AST copy and per-terminal allocation sites
grep -rn -- '->copy()' src/QueryBuilder.php src/Internal/Compiler/AbstractDialectCompiler.php
grep -rn 'CompilerFactory::for\|new Executor' src/

# SQ-0402-09 documentation overlap line counts
wc -l docs/reference/public-api.md tests/Fixtures/Contracts/public-api.json \
  docs/maintainers/testing-strategy.md docs/maintainers/testing-architecture.md
ls docs/evidence/*.md docs/evidence/*.json | wc -l
```

## Update rule

A task may resolve or reduce an item only when a paired before/after record
shows identical SQL, bindings, exceptions, and results (or the explicitly
accepted exception for that item). After the item's task lands, write the new
"after" metrics into the JSON and adjust the "before" baseline only with a
plan revision and evidence.
