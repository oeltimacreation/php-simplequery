# `v0.3.0` development baseline

Collected: 2026-08-01

This record freezes the public-source, public-contract, synthetic-query,
coverage, test-result, and benchmark comparison points at immutable tag
`v0.3.0`, commit `2c5a1f231d12e06410a9fe8050b7a22906014618`. The exact values
are in the [machine-readable baseline](v0.3.0-development-baseline.json).

This is the `0.4.0` Phase 0 baseline (SQ-0401): every refactor in this release
must be validated against these values, and any change to a recorded digest is
a prompt for semantic review, not proof of regression by itself.

## Public contract source

The baseline contains 30 public PHP files under `src/`, excluding the closed
`src/Internal/` implementation. The recorded digest covers each sorted path and
its Git blob ID, so both public type names and their exact tagged declarations
are recoverable without copying a second source tree into the documentation.

Reproduce the public-source digest from a clone containing the tag:

```bash
git ls-tree -r --name-only v0.3.0 src \
  | rg '\.php$' \
  | rg -v '^src/Internal/' \
  | sort \
  | while IFS= read -r file; do
      blob=$(git rev-parse "v0.3.0:$file")
      printf '%s  %s\n' "$blob" "$file"
    done \
  | sha256sum
```

## Public contract manifest

The reflection-based public API signature manifest at
`tests/Fixtures/Contracts/public-api.json` is a Phase 0 baseline input. Its
SHA-256 digest (`2f32eaf16cea0b42ac0c412921c0929c356643d7909fef57691509c21ac728cf`)
is recorded in the machine-readable baseline. `composer public-api:check`
regenerates the manifest in memory and fails when the checked-in record
differs; `0.4.0` must keep this manifest byte-identical to `v0.3.0`.

## Synthetic queries

SHA-256 digests are recorded for the MariaDB, MySQL, and SQLite compiler
goldens, feature-coverage catalogue, public aggregate and connection contracts,
the public API manifest, and both migration corpora. Reproduce an individual
digest with:

```bash
git show v0.3.0:tests/Fixtures/Compiler/mysql.json | sha256sum
```

## Test results

`composer test` on PHP 8.4.24 with `pdo_sqlite` passes 441 tests and 1,917
assertions. The full `composer check` gate (lint, tests, PHPStan library and
level-9 consumer, PHPCS, public API manifest, documentation links, examples,
migration corpus, repository structure) is green on this tree.

## Benchmarks

The baseline records the maintained CI, historical-shape, migration, observer,
production, reference-size, soak, and query-plan commands plus digests for the
scenario catalogue, runner, comparison harness, migration benchmark, and
committed migration control. Benchmark comparison must use the same PHP
runtime, PDO driver, database settings, workload profile, and correctness
digest; timings from unlike environments are not comparable. The paired
`v0.3.0` comparison for later work is `v0.2.0` per
[`0.3-production-performance.md`](0.3-production-performance.md).
