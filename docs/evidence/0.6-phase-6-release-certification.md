## Paired `v0.5.0` baseline benchmark comparison

### Noise control and timing policy

The identical-source noise control (`benchmarks/noise.php`, 5 runs) established a host absolute timing noise floor of **0.565028 ms**. In accordance with the benchmarking policy:
- Sub-millisecond operations whose absolute change remains below 0.565 ms are treated as non-actionable host variance.
- No repeatable actionable regressions occurred across both source orders.

## Security and boundary audit

1. **Raw SQL boundaries:** `raw()` and `query()` remain explicit trusted-code boundaries. Structured query builder inputs are compiled strictly through parameterized placeholders; direct value interpolation into SQL is impossible.
2. **Identifier sanitization:** All table and column identifiers are validated and escaped using dialect-specific quoting. Wildcard positions are strictly checked; conflicting table aliases reject with `InvalidQueryException`.
3. **Binding normalization:** Ordered binding lists maintain exact 1-to-1 correspondence with SQL `?` placeholders. Concrete scalar types (`int`, `float`, `string`, `bool`, `null`) are preserved.
4. **Generated IDs:** IDs are returned as strings directly from driver `lastInsertId` or sequence queries, preventing 64-bit integer overflow.
5. **Diagnostic redaction:** `QueryExecutionException`, `TransactionException`, and all error types guarantee that parameter bindings, connection passwords, and DSN credentials are never disclosed in exception messages or diagnostic chains.
6. **Transaction state integrity:** Cross-connection transaction mixing is rejected. Unmanaged commits/rollbacks outside `TransactionManager` transition the connection to an unusable quarantine state to protect data safety.
