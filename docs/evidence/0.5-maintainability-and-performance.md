# `0.5.0` maintainability and performance evidence

Date: 2026-08-17

Baseline: immutable `v0.4.0` (`e1ef08ac89a527b3e176e3c969da3bd967b5f817`)

Candidate: `feature/0.5-candidate` working tree

## Baseline and reduction

The maintained-line measurement excludes generated reports, ignored output,
dependencies, documentation, and product `src/`, using:

```bash
find tools scripts benchmarks tests -type f \( -name '*.php' -o -name '*.sh' \) \
  -print0 | xargs -0 wc -l
```

| Measurement | `v0.4.0` | `0.5` candidate |
|---|---:|---:|
| Maintained PHP/shell lines | 14,695 | 10,286 |
| Maintained files | 112 | 72 |
| Composer script entries | 34 | 23 |
| Public manifest types | 30 | 30 |
| Public manifest members | 196 | 199 |
| PHPUnit tests / assertions | 501 / 2,089 | 431 / 1,224 |
| CI benchmark scenarios | 23 | 19 |

The line result is a 30.0% reduction and reaches the release ceiling after
the conditional and pagination tests were added. The three new manifest
members are `QueryBuilder::when()`, `unless()`, and `forPage()`.

## Quality and behavior

The unchanged release floors are 90% overall line, 80% overall branch, 95%
compiler line, and 90% compiler branch coverage. The candidate measured:

| Gate | Candidate result |
|---|---:|
| Overall line | 94.70% |
| Overall branch | 91.04% |
| Compiler line | 97.27% |
| Compiler branch | 91.48% |

`composer check` passed with 431 tests and 1,224 assertions. The SQLite
behavior, execution, and transaction probes passed with 12, 16, and 16
observations respectively; the dedicated contention probe passed its busy,
timeout, and four-writer stress checks.

## Security review

The new API adds no raw SQL, identifier, execution, transaction, or diagnostic
input boundary. Conditional callbacks are explicit trusted closures; pagination
accepts strict integers, validates positivity and multiplication overflow before
mutation, and reuses the existing limit/offset compiler path. Exact compiler
tests cover the normalized binding order, and the existing raw SQL, redaction,
transaction, and ambiguous-write checks remain unchanged.

## Correctness-gated performance and memory

The compact runner accepted correctness digests for all 19 CI scenarios and
all 4 soak scenarios in fresh worker processes. It retains paired operation
medians, allocation samples, retained allocation, file descriptors, PHP peak
allocation, and RSS. The soak run recorded zero retained growth and zero
retained peak growth for every operation; the largest observed worker RSS was
44,668,864 bytes. The existing 256 KiB retained-growth gate remains active.

The release comparison command is configured to run the same compact scenario
set against a fresh `v0.4.0` worktree. A pinned local nine-sample, three-warm-up
run preserved digest parity for all 19 scenarios and produced no compiler or
terminal review signal above 5%; its only review flag was a non-blocking
`pdo_control_100/pdo` change of +5.395%. The current local Docker matrix
passed direct MariaDB 11.8.8/MySQL 8.0.46 and ProxySQL/MaxScale paths; the
minimum matrix also completed against MariaDB 11.8.2 and MySQL 8.0.11. Reports
were disposable and are not committed.

Historical migration, query-plan, duplication, and 0.4 performance records
remain archived. Their retired generators are not active 0.5 tooling.
