# `0.5.0` development plan

Status: Phase 0–5 complete; Released. Baseline: released `v0.4.0`.

## Release outcome

`0.5.0` is a maintainability-first performance, efficiency, stability, and
code-quality release. It adds one small public feature family while reducing
the development surface that accumulated around historical migration,
benchmark, probe, and duplication work.

The maintained developer surface is measured with:

```bash
find tools scripts benchmarks tests -type f \( -name '*.php' -o -name '*.sh' \) \
  -print0 | xargs -0 wc -l
```

The `v0.4.0` baseline is 14,695 lines. The release target is at most 10,286
maintained tooling and test lines after the new feature tests are included.
Generated JSON, ignored reports, dependencies, documentation, and `src/` are
not part of this measurement. No formatting or comment deletion may be used
to satisfy the target.

## Public feature

Add these methods directly to `QueryBuilder`:

```php
when(mixed $value, Closure $callback): self
unless(mixed $value, Closure $callback): self
forPage(int $page, int $perPage): self
```

`when()` invokes its callback for a truthy value. `unless()` invokes it for a
falsey value. Each callback receives only the current builder, its return value
is ignored, exceptions propagate unchanged, and the method returns the same
builder instance. No fallback callback is provided.

`forPage()` is strict and 1-based. Page and page-size values must be positive;
offset multiplication overflow is rejected before state changes. It replaces
existing limit and offset values through the existing mutation semantics and
does not add ordering, execute a count query, or implement cursor pagination.

The helpers are not added to `ConditionGroup` or any internal extension
surface. Other deferred 0.4 features remain out of scope, including CTEs,
existence predicates, scalar terminals, chunking, SQL inspection helpers, and
additional raw-expression overloads.

  SQLite integration tests before deleting migration tests.

  required-file inventories to match the reduced tree.

## Explicit non-goals

The release does not add an ORM, schema or migration API, connection pool,
retry engine, global connection state, public compiler/dialect extension
platform, named-placeholder builder support, or hidden replay of uncertain
writes. Supported database and proxy claims remain unchanged.
