# Development plans

This directory contains only active release planning:

- [0.3 development plan](0.3.md)
- [0.4 development plan](0.4.md)

A plan describes intended work, acceptance gates, and explicit non-goals. It
is not part of the released public API contract. When a release is complete,
remove its plan and preserve the durable outcome in `CHANGELOG.md`, the upgrade
guide, relevant ADRs, and evidence records.
