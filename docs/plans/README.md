# Development plans

This directory contains only active release planning:

- [0.7 development plan](0.7.md)

A plan describes intended work, acceptance gates, and explicit non-goals. It
is not part of the released public API contract. When a release is complete,
remove its plan and preserve the durable outcome in `CHANGELOG.md`, the upgrade
guide, relevant ADRs, and evidence records. The completed `0.6.0` plan was
retired when `0.7.0` planning began; its outcome is recorded in the `0.6.0`
changelog section, the upgrade guide, and the
[`0.6.0` release certification evidence](../evidence/0.6-phase-6-release-certification.md).
